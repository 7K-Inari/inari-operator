# inari-operator-crds

CustomResourceDefinitions (group `platform.inari.io`) for the Inari platform
operator. The files under `templates/` are verbatim copies of
`config/crd/bases/` (generated by controller-gen via `make manifests`) —
synced by `make chart-crds` and drift-checked in CI
(`scripts/chart-crds-sync.sh --check`).

## Install order

1. `inari-operator-crds` (this chart)
2. `inari-operator`

On upgrade, apply this chart **before or together with** `inari-operator` so
the operator never runs against CRD schemas older than its code.

## Uninstall

Deleting this chart deletes the CRDs and therefore **all custom resources** of
these kinds. Do not uninstall unless you are tearing down the platform.
